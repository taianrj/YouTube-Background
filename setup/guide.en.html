YouTube Background

Control video from any window · version 1.2.3

1. Add the extension to Chrome

  1. Open Chrome and enter chrome://extensions.
  2. Enable Developer mode and click Load unpacked.
  3. Paste %LOCALAPPDATA%\YouTubeBackground\extension into the folder picker's address field and select that folder.
  4. Reload any YouTube tabs that were already open.

If the extension is already installed, click Reload at chrome://extensions after updating its files. You do not need to add another copy.

Incognito windows (extension 1.0.1 or later): open the extension's Details and enable Allow in Incognito. Reload the YouTube tabs in that window. The most recently started video still playing across normal and Incognito windows receives hotkeys. Its title may also appear in the tray menu; it is not saved in a history.

2. Record your hotkeys

  1. Open YouTube Background from the Start menu, or right-click the red tray icon near the clock and choose Settings.
  2. Click Record next to Skip backward or Skip forward.
  3. Press a key combination or turn the keyboard dial once. Check the detected key name.
  4. Set the interval from 1 to 120 seconds and click Save. Esc cancels recording.

The default is Ctrl + Alt + ←/→, with 5-second skips. If you assign Volume +/−, those keys control video instead of volume while hotkeys are active. Suspend hotkeys restores normal behavior. Manufacturer-specific dials may need remapping in the keyboard software.

3. Test it

Play a YouTube video, open another window and press a hotkey. If several videos are playing, the most recently started one is controlled. Paused videos are not skipped.

When you need help

Chrome disconnected: check that the extension is enabled and wait for reconnection. Hotkey in use: choose a different combination. Chrome must remain open.

You can change startup behavior in the settings. To remove the app, use Windows Settings → Apps → YouTube Background → Uninstall and remove the extension in Chrome. Preferences are kept for a future reinstall.
